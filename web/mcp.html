Attach VisaRadar to your AI agent

VisaRadar ships an MCP server, so Claude, or any MCP-compatible client, can call it directly as a tool.

Install

pip install -e ".[mcp]"

Configure your client

Add to your MCP client's config (e.g. Claude Desktop's claude_desktop_config.json, or Claude Code's .mcp.json):

{
  "mcpServers": {
    "visaradar": {
      "command": "visaradar-mcp"
    }
  }
}

If it's not on your PATH, point at the venv directly instead:

{
  "mcpServers": {
    "visaradar": {
      "command": "/path/to/VisaRadar/.venv/bin/visaradar-mcp"
    }
  }
}

Tools it exposes

tool
visaradar_company(name)

Direct lookup against real DOL filing history. No LLM call, no posting text needed.

tool
visaradar_check(posting_text, model?)

Extracts company/title/sponsorship-stance from a job posting via an LLM, then cross-references the real filing data. Uses your configured provider, or pass model to override for that call.

Why this matters

Once attached, an agent doing job-search help for you can just call visaradar_company mid-conversation — no copy-pasting CLI output back and forth.
