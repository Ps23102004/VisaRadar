Install & use the CLI

The web pages here are a companion viewer. The real tool is a local Python CLI.

Install

# clone the repo, then:
pip install -e .

# or, if you want the historical-data rebuild tooling too:
pip install -e ".[update]"

Prerequisite: an LLM backend

Local (free, default): Ollama running at 127.0.0.1:11434 with a model pulled. Or any OpenAI-compatible API — OpenRouter, Groq, Together, LM Studio, vLLM, OpenAI itself.

Commands

CommandWhat it does
radar check "<posting>"Full pipeline: LLM extraction + real filing-data match
radar check --file posting.txtSame, reading the posting from a file
radar check --url https://...Same, fetching the posting from a URL
radar company "Google"Direct lookup, no LLM call at all
radar configShow resolved provider, data dir, snapshot info
radar historyShow your recent check history

Use any provider

radar check "..." --model openrouter/google/gemini-3.7-flash
# export the provider's key first:
export OPENROUTER_API_KEY=...

Local-first storage

Every check is logged to ~/.visaradar/history.jsonl, and written as a Markdown note to ~/.visaradar/notes/. Point --data-dir at a folder inside your own Obsidian vault and lookups show up there as normal notes.
